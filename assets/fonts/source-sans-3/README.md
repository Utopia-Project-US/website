# Source Sans 3 Controlled Font Package

This directory contains the six static TrueType faces authorized for
Redrafting America controlled documents.

- Family: Source Sans 3
- Upstream version: 3.052
- Upstream release tag: `3.052R`
- Release date: 2023-04-04
- Source: https://github.com/adobe-fonts/source-sans/releases/tag/3.052R

Install these files at the operating-system level before editing a controlled
Word master. Published PDFs must embed the fonts. Controlled DOCX files must
embed all characters from every face they use. Arial is the required fallback
when Source Sans 3 is unavailable.
